# Venues (SCI/SCIE) and what they expect
| venue | type | fit for | expects |
| --- | --- | --- | --- |
| Empirical Software Engineering (Springer) | journal, SCIE | registered report of the protocol + pilot | hypotheses and analysis plan reviewed before results; negative results welcome |
| IEEE TSE / ACM TOSEM | journal, SCIE | P1+P3 combined, n >= 40, >= 2 teams | threats-to-validity, replication package, effect sizes with CIs |
| Journal of Systems and Software | journal, SCIE | tooling + evaluation | reproducibility, baselines |
| IEEE Software | magazine, SCIE | practitioner summary after results | short, concrete, lessons learned |
| IEEE RA-L | journal, SCIE | P2 embodied hypotheses | hardware or high-fidelity sim, 8 pages, fast review |
| ASE / ICSE industry track | conference | single-team experience report | candour about what resisted |

Replication package = both repositories at tagged commits + `.project-os/metrics.jsonl` + `docs/research/evidence/`.
